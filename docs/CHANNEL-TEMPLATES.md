# 按通知渠道设置模板

通知渠道 → 新增或编辑 → “该渠道专属通知模板”。分别配置聊天、发货、账号状态；留空使用已有全局模板。
使用原版 `{{message}}`、`{{buyer_nick}}`、`{{account_id}}` 等变量，字段旁列出支持列表。
预览与发送使用同一渲染器，未知变量/残缺括号在保存时提示，消息内容不二次解释为模板。
配置存入渠道现有JSON字段，不改变表结构。编辑保留其他配置字段；预览不向外发送。

聊天与发货显式传入买家、商品、会话、消息等上下文，发货支持order_id；缺失金额/数量显示“未知”，不伪造交易数据。
账号通知有detail、验证链接等上下文。账号备注从对应账号记录读取。
测试通过本地HTTP接收器核对两个渠道实际收到不同正文；不请求用户生产通知渠道。

预览中的账号变量使用示例备注；正式分发读取真实账号备注。旧字符串配置在渠道列表按纯文本显示。回归与浏览器验收见 `UPSTREAM-TESTING.md`。

2026-10-07修复：手动密码登录的链接/截图分支、手动导入Cookie的验证通知均传递 `verification_url`、`verification_info`、`detail`，渠道模板保留验证入口。此修复只涉及通知上下文，不改变登录冷却或平台验证结果。
