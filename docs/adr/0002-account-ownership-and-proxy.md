# 单账号执行权与故障停止

同一闲鱼账号只能由一套系统持有执行权；刷新凭据保留账号资料，恢复、验证和后台任务共享该执行权。普通断线先重连和刷新，凭据失效才用账密重登；连续失败两次或反复失效后暂停告警，手动停用保持停用；自动滑块最多两次，再交人工，短信和人脸验证直接交人工。

账号保持绑定代理，代理或其依赖异常时停止业务操作；不沿用两来源中代理失败后继续尝试未绑定账号代理的连接路径。这里选择明确暂停而非优先维持表面在线，代价是故障期业务暂缓，收益是避免抢登录、反复验证及出口意外改变；具体退避时间和判定窗口由规格落成可配置参数。

确认依据：用户先前逐项同意账号恢复、验证接管与固定代理三条规则；本轮总体确认。

本记录描述已接受的设计方向，不表示代码已实现或已通过业务验收。
