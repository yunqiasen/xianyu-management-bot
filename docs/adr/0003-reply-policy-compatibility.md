# 双回复策略与连续会话语义

两个来源的回复优先级不同；直接把GuDong商品专属回复塞入原版商品默认字段会改变回复行为。迁移GuDong账号保留商品专属→商品关键词→通用关键词→默认→AI的旧策略；新账号采用商品专属→商品关键词→通用关键词→AI→默认的策略，并在界面显示、允许主动切换；商品专属回复与商品兜底不是同一规则。

兼容两种策略增加测试组合，但避免迁移时默认行为突变，同时解决新账号默认模板挡住AI的问题。人工与机器人共享连续会话历史，按账号和会话隔离；明确区分正文与跳过结果，AI测试与实际回复共用协议调用链。

确认依据：完整方案及上一条回复明确提出两种策略，用户回复“可以，上手,用这个工作流上手”。

本记录描述已接受的设计方向，不表示代码已实现或已通过业务验收。
