## 前端入口

- 通知渠道 → 新增/编辑 → 该渠道专属通知模板（三类，预览不发送）。
- 商品发布 → 平台类目与属性 → 推荐类目、候选/属性选择、清除。
- 商品发布 → 素材库 → 分页/条数；素材保存/载入保留选择。

详细约定见 `CHANNEL-TEMPLATES.md`、`PUBLISH-CATEGORIES.md`、`ACCOUNT-RECOVERY.md`。
