# 商品、发布及运营任务

对应 DEV-10、23–25、31。

- 商品同步/搜索逐页校验并按商品ID去重；局部失败保留已确认数据。真实空结果、凭据问题、限流和结构错误分别返回，Retry-After 保留。
- 发布能力先查鱼小铺；只有明确无卖家工作台的业务结论才探测个人版。未知业务错误、代理或限流不推断为普通卖家。多规格能力及类目仍以平台结果为准。
- 素材校验规格维度、值、来源ID、笛卡尔积SKU、价格和整数库存；素材编辑不改既有发布快照。图片/视频资源按所属用户校验引用。
- 单品与批次保留持久请求身份和逐件日志；取消停止尚未执行项，仅明确失败项能重试。缺少平台商品身份/回执进入unknown；核对后再推进，不新发一件同样商品。
- 商品本地删除与平台下架/删除分开，平台操作先记录意图；账号、商品、关联卡券按归属限定。
- 发布、搜索、同步、图片/视频、擦亮、评价、小红花的实际外发均走已有账号执行方、固定代理和共享预算。
- 擦亮支持账号时区、跨午夜窗口、持久周期与随机窗口内计划。随机计划先持久保存，重启不重新抽取；迁移保留原next_run与周期，旧delay_minutes按源码小时语义处理。错过周期记跳过，不集中补跑；手动触发也遵守预算，旧开关不因升级开启。
- 评价/小红花提供模板、激活、单笔/批次及历史结果；持久防重、适用性和冷却区分已处理/跳过/失败/待核实。小红花是请求评价，不是保活。

## 界面与接口

原 Items、素材、单品/批量发布、日志和运营入口保留；`ProductBatchControls`、`ProductFeedback`、`PolishWindow`、`ItemOperationHistory` 展示操作身份、阶段、部分结果和明确重试。

## 验证

`tests/products/` 及其真实浏览器场景覆盖素材/SKU往返、取消/单项重试/未知核对、时间窗、评价与小红花。`tests/dispatch/test_platform_gateway.py`、`test_remote_media.py`、`test_video_upload.py` 从实际RPC和网络边界验证出站。生产平台类目、账号能力及真正发布结果仍需单独试跑。
