# 账号、配置与登录维护

对应 DEV-02–09；接口见 [API](../API.md)，操作见 [使用说明](../OPERATIONS.md)。登录资料、后台身份与业务可用性分开。

## 当前链路

- 新建、Excel、手动替换、扫码刷新均经 `AccountService` 保留资料和持久凭据任务。凭据检查成功才采用新值；旧任务、取消和超时的结果不覆盖新值。查询和取消先核对凭据版本、配置版本与执行代次，过期绑定记为 `superseded`，只结束旧任务，不暂停新会话。新建/自动恢复只合并当前仍有效的任务；到期任务在替换前结束。
- `unb` 是平台身份，跨后台用户和不同展示账号ID也保持唯一。增量迁移先检查重复和身份矛盾，冲突时停止迁移，不合并账号。新增不透明操作/事件身份使用MySQL 8 `utf8mb4_0900_bin`，保留大小写及尾空格。
- 留空或使用脱敏占位保留已有账密、代理认证；清除使用独立 `clear_fields`。手动停用经凭据维护、重启和配置应用仍保留。
- 删除先查影响；未完成消息、账号操作、履约等关联阻止删除，资料采用软删除，不清理业务事实。
- `AccountRuntime` 使用 Redis 租约与代次、MySQL 配置/凭据版本共同约束。Web、调度调用已有消息执行方；聊天页不另建登录连接。
- WebSocket 注册收到有效确认后才显示业务可用；发送注册包、打开页面和保存配置均不等于账号恢复。

## 恢复与人工验证

`account_renewal` / `AccountRecovery` 是主动保活、定时刷新、Token 更新和密码恢复的共同入口。普通网络故障、代理异常、限流分别处理；只有凭据失效进入适用的账密恢复。一次恢复链内部共用两次预算，第二次等待60秒附近；连续失败和反复失效窗口保持持久状态。

`AccountBrowserSessions` 保留同一页面的截图、指针按下/拖动/释放、取消及完成检查。一账号一验证会话，15分钟或更早的平台期限到期后释放浏览器。验证码自动尝试总预算为两次，随后保留人工入口。HTTP 407 单独标为代理认证故障；取消/超时删除临时截图内容。

## 固定代理

HTTP、WebSocket、登录浏览器读取同一账号绑定。支持显式 none、HTTP、HTTPS、SOCKS5；缺少相应客户端能力时停止并显示原因，不借用环境代理。HTTPS CONNECT 和认证失败有真实本地代理通信回归。订阅转换及宿主机/容器地址见使用说明。

## 配置继承

`TypedSettings` 注册九项：暂停分钟、回复延迟秒、相同消息等待秒、擦亮、评价、小红花、显示浏览器、买家信誉规则说明、共享请求频率。旧账号列默认是显式值，只有主动选择继承才按用户默认→系统默认→内置默认取值。

- `false`、合法 `0`、空字符串、可空字段的 `null` 与继承分别处理；页面显示类型、范围、有效值、来源及版本。
- 有效值在事务内投影到原账号列或 runtime，不另建消费者配置真相。
- 保存与 Web/消息/调度应用分别记录；只补缺失消费者；CAS 丢弃旧保存和旧确认，不把应用成功显示成账号已登录。
- 原编辑入口转为显式覆盖并递增版本。Excel只修改存在的列，一个文件为一轮配置事务，不使同批凭据任务过期。
- Excel及原表单同步实际买家信誉规则；关闭规则同步关闭关联动作。资料中的时长按注册范围校验。
- `xymb.account.defaults` 由启动迁移创建，只经专用接口写入；通用设置接口保护该键。

## 验证入口

`tests/accounts/`、`tests/dispatch/test_renewal.py`、`test_proxy_transport.py`、`tests/runtime/scheduler_config_suite.py`；`tests/accounts/browser_policy.py` 操作真实配置面板和离线消费者。`test_api.py` 覆盖旧任务轮询/取消、旧绑定重开任务和到期替换；`test_recovery_chain.py` 覆盖自动与人工旧任务均不挡住新恢复。`test_infrastructure.py` 使用真实隔离 MySQL/Redis 验证身份竞争、任务合并和并行消费者确认。

这些验证使用合成账号与可控通信端点。真实账号的扫码、短信、人脸和长期续期结果属于独立发布验收。
