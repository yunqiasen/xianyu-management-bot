# 模型配置、预设与实际回复

对应 DEV-16–19、22；议价增强另见 [bargaining](bargaining.md)。

## 契约

统一 `AIGateway` 支持 OpenAI Chat Completions、Responses、Azure、Anthropic、Gemini、DashScope应用六种协议。Ollama使用明确兼容模式；未知协议保存时报错。

服务根地址和完整地址只规范化一次；Azure显式部署名/API版本/认证方式，DashScope应用ID与模型名分开。测试按钮与真实回复使用相同配置、超时、请求及解析；保存成功、测试成功、会话实际采用AI是三个结果。

密钥留空或占位保留原值；预设按用户隔离，应用时复制快照并逐账号返回结果，删除预设不影响账号副本。提示词支持既有格式并验证输入，不将坏JSON静默替换。

模型异步调用，默认60秒超时且不自动再次生成；默认输出512 token、上下文24000字符，页面保存实际配置。错误记录阶段、HTTP状态、协议原因码、调用ID及配置版本；空响应、明确跳过、错误兜底分开。账号/配置变化或人工暂停使旧生成结果过期；发送前另有规则和执行权复核。

## 历史

真正回复从 `ReplyState` 共享历史取已确认买家、人工和机器人消息，而非仅查AI生成表。诊断给出采用范围与裁剪数；P5开关打开时按最新完整往来裁剪，已确认的议价事实与历史清理独立。

## 页面与数据

`Accounts` 已挂载 `AISettingsPanel`，独立AI配置页使用同一面板。预设表和账号扩展配置已纳入公共模型及迁移；SQL日志关闭参数回显，接口/错误不返回完整密钥。

## 验证

`tests/ai/` 从真实API/SQL到独立本地HTTP逐协议检查URL、认证、请求、成功/认证失败/业务错误/超时/空或畸形响应；`tests/replies/live_ai_suite.py` 在实际回复选择链再次验证。真实Chromium操作保存、测试、预设CRUD、部分批量应用和删除后的账号调用。

所有模型端点是测试端点；正式供应商模型、实际账号对话属于独立业务试跑。不要把本地协议样本称为真实上游可用性保证。
